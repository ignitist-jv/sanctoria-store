# Prayer Song: "who a prayer song can be for" tile image prompts

Ten hyper realistic tiles for the dark grid section. Generate at 4:5 portrait. The page shows each tile at about 1 : 1.12 (width to height), so a little is trimmed from the top and bottom: every prompt keeps headroom and a plain lower third for that reason. The white serif label sits over the bottom third on a dark gradient, so that zone is kept dark and low in detail in every image.

These are illustrative scenes of the people a song can be for. They are not customers and not testimonials, and nothing in any image implies an outcome.

Casting across the set, so the grid reads as one family album and not a poster: white (1, 6, 7, 10), Hispanic (2, 5), Filipino (3), Black (4, 8). Light sources alternate between window daylight and one lamp, all under the same warm muted grade.

Generation notes:
- Paste each prompt whole. The style block is identical in all ten; do not edit it per tile or the set will drift.
- Generate tile 1 first, approve it, then attach it as a style reference for the other nine if the model accepts reference images.
- Reject any render with readable text, a face or bright object in the bottom third, a subject looking into the lens, or visible hands that look wrong.
- Check every pick at 105 px wide before shipping. If the subject does not read at that size, regenerate closer.
