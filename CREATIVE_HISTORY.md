# divine-grace-gift — Creative History Log

Append-only log of every image prompt ever generated for this project.
The `/generate-ads` workflow reads this file in Phase 4 to ensure every new design is **different** from past ones (unless explicitly overridden).

## How to read this

Each section is dated. Within a section, each entry lists:
- Concept name
- Subject / setting / mood / lighting / camera / palette / style / era

When generating new image prompts, scan this file and avoid duplicating any combination of these elements.
